- 실행일: 2026-08-23 KST
- 기준 분기: OA-22176/OA-22173 모두 `2026Q1`
- 상태: `preview_only`
- production `spending_intent`: 변경 없음

## 결론

분기 baseline의 주 후보는 **후보 A: `district_total_sales / district_total_matched_stores` percentile**이다. 매출 1,531개 grain이 OA-22173에 100% exact match했고, 이 지표와 matched 점포 수의 상관은 0.0059로 총매출의 규모 편향 0.8145를 크게 제거했다. 후보 B는 큰 매출 업종을 다시 매출액으로 가중하여 극단값을 증폭하고, 후보 C median은 안정적이지만 자치구 총 소비 강도를 지나치게 버린다.

실시간 보정의 주 후보는 **후보 C: 장소별 `payment_amount_midpoint`의 서울 82곳 percentile을 계산한 뒤 자치구에서 평균**하는 방식이다. raw 금액 평균보다 outlier에 덜 민감하고, 합산하지 않으므로 장소 수가 많은 구가 자동으로 유리하지 않다. 다만 history 상대비율 후보 D가 충분한 동시간대 표본을 확보하면 다시 비교해야 한다.

## OA-22385 payment snapshot

82개 장소 모두 다음을 보존했다.

```text
area_cd, area_nm, assigned district
payment_count
payment_amount_min, payment_amount_max, payment_amount_midpoint
commercial_level
source_timestamp, received_at
industry_commerce[]:
  RSB_LRG_CTGR, RSB_MID_CTGR, RSB_PAYMENT_LVL,
  RSB_SH_PAYMENT_CNT, RSB_SH_PAYMENT_AMT_MIN/MAX,
  RSB_MCT_CNT, RSB_MCT_TIME
```

실제 표본 `POI009 광화문·덕수궁`은 `CMRCL_TIME=20260823 1540`, level `보통`, 결제 106건, 금액 1,500,000~1,600,000원, midpoint 1,550,000원이었다. 업종 배열도 한식 등 실제 응답 필드를 그대로 저장했다. 이는 신한카드 기반 proxy이며 정확한 전체 실시간 매출이 아니다.

### amount/count/level 관계

| 관계 | Pearson | rank 상관 |
|---|---:|---:|
| amount midpoint vs payment count | 0.4873 | 0.8810 |
| level ordinal vs amount midpoint | 0.4981 | 0.6177 |
| level ordinal vs payment count | 0.2402 | 0.4681 |

level ordinal은 공식 순서 `한산한 < 보통 < 바쁜 < 분주한`을 diagnostics에서만 사용했다. level은 장소 자신의 과거 동시간대 대비 상대 활성이고 amount/count는 현재 절대 proxy이므로 순위가 완전히 일치하지 않는 것이 자연스럽다.

금액 median은 900,000원, 최대는 압구정로데오거리 21,500,000원이다. IQR 기준 금액 상단 outlier는 10곳이며 압구정로데오거리, 강남역, 홍대·종로청계·명동 관광특구, 신촌·이대역 등이 포함된다. raw 평균의 outlier 민감도가 확인됐다.

## history와 중복 방지

`latest/`에는 최신 전체 payment snapshot, `history/YYYY-MM-DD/HHMM/`에는 시간별 snapshot을 저장한다. 같은 `AREA_CD + CMRCL_TIME`은 history에 다시 만들지 않으며 latest만 안전하게 갱신한다.

`same_band_history_preview`는 caller가 같은 요일·시간 band로 선별한 history에 한해서 다음 schema를 반환한다.

```text
current_payment_amount, same_band_history_avg, payment_amount_ratio
payment_count_current, payment_count_history_avg, payment_count_ratio
history_snapshot_count, source_status, preview_only
```

현재 동일 band history가 충분하지 않으므로 ratio는 official metric으로 선택하지 않았다.

## TourAPI/OA-21285 budget preview

실제 25개구 sales 후보 A percentile, 기존 2025-09 TourAPI bonus, OA-21285 누적 snapshot percentile, OA-22385 후보 C를 사용했다. 콘텐츠·날씨·특일은 요청별 값이라 제외했다. `cap3`와 OA-22385 0~10 표현은 비교 전용 가정이다.
