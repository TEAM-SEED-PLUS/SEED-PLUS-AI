# [F] 소비 의도 데이터 계층 및 calibration preview

- 기준일: 2026-08-23 KST
- 분기 기준선: OA-22176 `2026Q1` (`STDR_YYQU_CD=20261`)
- 실시간 reference: OA-22385 2026-08-23 live probe
- 상태: **preview_only / production spending 산식 미변경**

## 결론

OA-22176의 정확한 명칭은 `quarterly_sales_baseline`이다. 월 기저로 표현하지 않는다.

baseline 추천은 **점포당 추정매출 percentile을 주 후보로 두되, OA-22176과 상가정보의 업종 모집단을 정합화하기 전에는 production에 사용하지 않는 것**이다. 총매출은 점포 수와 Pearson 상관계수 0.8298로 규모 편향이 뚜렷하다. 면적당 매출은 총매출과 상관 0.3087이지만 중구처럼 작은 행정구역을 과도하게 높일 수 있다. 따라서 총매출과 면적당 값은 각각 시장 규모·공간 집약도 diagnostics로 유지하는 편이 낫다.

OA-22385는 카드 결제량을 과거 동일 장소·요일·시간대와 비교한 **상권 활성 수준**이다. 정확한 실시간 총매출액이 아니다. 82개 장소 모두 OA-21285 코드·이름 체계와 일치하여 기존 geometry mapping을 재사용할 수 있지만, 장소가 없는 중랑구와 자치구별 장소 수 편차 때문에 aggregation 방식은 아직 선택하지 않는다.

### 지정 8개구 규모 편향 판독

- 강남은 총액 1위지만 점포당 9위(66.67)로 하락한다.
- 서초는 총액 5위(83.33)지만 점포당 16위(37.50), 면적당 16위(37.50)다. 많은 점포와 큰 면적의 규모 효과가 크다.
- 마포는 총액 11위(58.33)지만 점포당 24위(4.17)다.
- 중구는 총액 7위(75.00), 점포당 6위(79.17), 면적당 1위(100)다. 면적당 값에는 작은 행정면적 효과가 강하다.
- 금천은 총액 8위(70.83)지만 점포당·면적당 모두 3위(91.67)다.
- 송파는 세 후보 모두 상위권이고, 종로도 점포당 보정 후 순위가 오른다.
- 강서는 총액 12위(54.17)에서 점포당 18위(29.17), 면적당 19위(25.00)로 낮아진다.

## 자치구 realtime aggregation 후보

다음 세 후보의 구조만 만들었으며 값은 아직 `null`이다.

1. 장소 단계 단순 평균: 장소 수 합산 편향은 없지만 ordinal 간격을 동일하다고 가정해야 한다.
2. OA-21285 현재 인구 가중평균: 상권 규모를 반영하지만 유동과 소비를 다시 결합하여 double counting 위험이 있다.
3. 유효 장소 percentile/rank 집계: 장소 간 상대 비교가 가능하지만 시각·장소 모집단 통제와 ordinal 변환 결정이 필요하다.

모든 구에 `assigned_place_count`와 `valid_place_count`를 별도로 보존했다. 장소 수 자체는 소비값에 더하지 않는다.

## TourAPI contribution 구조 비교

여기서 범위는 calibration 후보를 이해하기 위한 예시이며 production 상수가 아니다.

| 구조 | baseline 성격 contribution 범위 | 판단 |
|---|---|---|
| A. 현재 + TourAPI(0~10) + 신규 baseline(가령 0~10) | 0~20 | 같은 소비 기저를 독립 가산하여 과대 반영 가능성이 가장 큼 |
| B. 추정매출 main(가령 0~10) + TourAPI 축소 관광 보정(가령 0~3 또는 0~5) | 0~13/15 | 추천. 측정 기저와 관광 특성을 역할 분리 |
| C. 기존 base 24 중 일부(가령 10)를 baseline 0~10으로 대체 + TourAPI 0~10 유지 | 고정 14 + 0~20 | 총 범위를 통제할 수 있으나 baseline 저점에서 기존 base 의미가 변함 |

현재 TourAPI의 소비강도 50%, 식음료 35%, 연령 다양성 15%, 최대 +10은 변경하지 않았다. production 설계 시 B의 축소 cap과 관광 특성만 남길 component를 별도로 확정해야 한다.

## OA-21285 중복 분석

- OA-21285: 사람이 얼마나 모여 있는지 나타내는 실시간 유동 수준과 소비 기회
- OA-22385: 카드 결제량 기반의 장소별 상업 활성 단계

원천과 의미는 달라 함께 유지할 수 있지만, 유동이 결제로 이어지는 관계 때문에 통계적으로 독립이라고 단정할 수 없다. 특히 OA-21285 인구 가중으로 OA-22385를 집계하면 같은 유동 신호가 가중치와 기존 spending contribution에 두 번 들어갈 수 있다. 동시 시계열을 축적해 상관·조건부 설명력을 확인하기 전에는 공통 cap이나 interaction을 결정하지 않는다.

## fallback 및 metadata

| baseline | realtime | preview mode |
|---|---|---|
| 정상 | 정상 | `hybrid_preview` |
| 정상 | 실패/무자료 | `baseline_only` |
| 실패 | 정상 | `realtime_only_candidate` |

남은 component는 재정규화하지 않는다. baseline loader는 `requested_quarter`, `source_quarter`, `age_quarters`, `source_status`를 제공한다. realtime loader는 `latest_source_time`, `received_at`, `age_minutes`, `source_status`를 제공한다. 저장 상태는 `ok/partial/no_data/failed/fallback`을 구분한다.

## 추천 production 구조와 남은 결정

```text
분기 점포당 추정매출 percentile (main baseline 후보)
  + 축소된 TourAPI 관광 특성 보정
  + 기존 콘텐츠·날씨·특일 신호
  + OA-21285 유동/소비 기회
  + OA-22385 장소 실시간 활성 보정 (coverage 충족 시)
```

확정 전 필요한 결정은 다음과 같다.

1. OA-22176 서비스업종과 상가정보 점포업종 분모의 정합 범위
2. 점포당 percentile의 base 대체 여부, 구간, 방향, cap
3. TourAPI 축소 cap과 남길 관광 component
4. OA-22385 ordinal 수치 표현 및 자치구 aggregation 방식
5. 최소 유효 장소 수·coverage, 중랑구 및 실시간 실패 처리
6. OA-21285/OA-22385 동시 history 기반 상관 검증과 공통 cap
7. 분기 fallback 허용 age와 방법론 변경 시 재기준화
